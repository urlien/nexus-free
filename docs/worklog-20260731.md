# 2026-07-31 工作日志

## Docker部署 + 一键启动

### 完成的工作

1. **Dockerfile**
   - 基于 Python 3.12 slim
   - 安装 requirements.txt 依赖
   - 复制 backend + frontend 代码
   - 暴露端口 8000

2. **docker-compose.yml**
   - 端口映射：8000:8000
   - 环境变量：从 .env 文件读取
   - 数据卷：./data:/app/data（持久化SQLite数据库）
   - 重启策略：unless-stopped

3. **start.sh（一键启动脚本）**
   - 自动检测是否有Docker
   - 有Docker → docker compose up -d --build
   - 无Docker → pip install + uvicorn 直接运行
   - 检查 .env 是否存在

4. **.env.example**
   - MiMo API 配置模板
   - DeepSeek API 备用配置（注释）

5. **.gitignore**
   - 排除 .env（敏感信息）
   - 排除 data/（SQLite数据库）
   - 排除 __pycache__/、*.pyc、.venv/、venv/

6. **README.md 更新**
   - 新增 Docker 部署方式
   - 保留 Python 直接运行方式

### 使用方法

```bash
# 1. 配置 API
cp .env.example .env
# 编辑 .env 填入 API Key

# 2. 启动
bash start.sh

# 3. 打开浏览器
# http://localhost:8000
```
